# Connect a Mac to KH Updater
1. First: the Mac has Tailscale on, signed in to the same network as the Mac Studio, and Printer Studio KH is in its Applications folder.
2. On the Mac Studio, open KH Updater, click "Connect a Mac" and keep the pairing code in view.
3. On the printer Mac, double-click "Connect to KH Updater.command", press Return to accept the name it shows, and type the pairing code. If macOS offers to install "command line developer tools", click Install, then double-click again.
4. Success: within 5 minutes the Mac's name appears in the Macs list in KH Updater, with Printer Studio beside it.
5. Nothing installs by itself: updates happen only when you click Update for that Mac in KH Updater.
