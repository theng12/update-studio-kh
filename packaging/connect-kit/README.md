# Connect a Mac to Update Studio KH
1. First: the Mac has Tailscale on, signed in to the same network as the Mac Studio, and Printer Studio KH is in its Applications folder.
2. On the Mac Studio, open Update Studio KH, click "Connect a Mac" and keep the pairing code in view.
3. On the printer Mac, double-click "Connect to Studio Launcher KH.command", press Return to accept the name it shows, and type the pairing code. If macOS offers to install "command line developer tools", click Install, then double-click again.
4. Success: within 5 minutes the Mac's name appears in the Macs list in Update Studio KH, with Printer Studio KH beside it.
5. Nothing installs by itself: updates happen only when you click Update for that Mac in Update Studio KH, or from the Studio Launcher KH icon in that Mac's menu bar.
